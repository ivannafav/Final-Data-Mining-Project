# Time Series Forecasting & Classification Project

## Overview
This project focuses on developing and evaluating models for both time series forecasting and classification using Python.

## Objectives
- Forecast selected time series variables using historical data  
- Build classification models to categorize instances into binary classes  
- Compare model performance using appropriate evaluation metrics  

## Methods
- Time series forecasting using statistical, machine learning, and deep learning models  
- Deep learning models for classification tasks  
- Cross-validation and performance evaluation  
- Feature selection and parameter tuning to improve model performance  

## Data
- Time series dataset with multiple variables (Y1–Y7)  
- Classification dataset with 171 instances and 23 features  

## Evaluation Metrics
- Forecasting: RMSE, MAE, MAD, MAPE  
- Classification: Accuracy, Sensitivity, Specificity, AUC  

## Outcome
This project demonstrates the application of predictive modeling techniques to both forecasting and classification problems, highlighting model comparison and performance evaluation.
